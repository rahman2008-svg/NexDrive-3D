# NexDrive 3D — Unity Project

A starter 3D arcade driving game project for Unity 2022.3 LTS. The city, road, car, HUD, touch controls and collectibles are generated by C# at runtime, so no external art assets are required.

## Features
- 3D city road and procedural buildings/trees
- Drivable car with keyboard controls
- On-screen mobile touch controls
- Follow camera, speed HUD and crystal pickups
- Android package ID: `com.nexvora.nexdrive3d`
- Android build method: `NexDriveBuild.BuildAndroid`

## Open in Unity
1. Install Unity 2022.3 LTS with Android Build Support, Android SDK & NDK Tools, and OpenJDK.
2. Extract this folder.
3. In Unity Hub choose **Add project from disk** and select this folder.
4. Open `Assets/Scenes/Main.unity` and press Play.
5. For local Android build, select File > Build Settings > Android > Switch Platform, then Build.

## GitHub + Codemagic
Push the whole project to a GitHub repository. `codemagic.yaml` contains the Android build workflow and expects a machine with the exact Unity Editor version and Android module installed. Unity Editor licensing/activation may require a valid Unity license file/credentials. Configure these securely in Codemagic environment variables/groups; never commit license files or credentials.

Important: Codemagic does not automatically provide Unity Editor on every build image. If the selected runner does not have Unity 2022.3.62f1 and Android Build Support installed, the workflow stops with a clear error. Use a Unity-capable runner or configure installation/licensing first. The included GitHub Actions workflow checks project structure only; it does not compile Unity or create an APK.

## Controls
- Keyboard: W/Up accelerate, S/Down reverse/brake, A/D or Left/Right steer, Space brake.
- Mobile: on-screen directional and accelerator/brake buttons.

## Notes
This is a playable starter prototype using Unity primitive meshes. It is not a photorealistic commercial game yet. Test and tune physics/performance on your target device. APK generation has not been verified in this environment because Unity Editor and Android build modules are not installed here.
